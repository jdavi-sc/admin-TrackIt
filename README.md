# admin-TrackIt

## ✅ Visão Geral

O **admin-TrackIt** é o módulo administrativo do sistema **TrackIt**, desenvolvido como parte do curso de **Desenvolvimento de Sistemas** na **ETEC Uirapuru**.

Ele oferece uma **tela de registro** e uma **página inicial** dedicadas aos administradores do sistema, com foco em aprendizado prático e estrutura limpa.
